# dev-log

실무에서 마주친 문제, 배운 것, 막혔던 지점을 짧게 기록하는 개인 개발 일지입니다.

## 기록 규칙

- **매일 3줄 이내**로: 오늘 한 일 / 막혔던 것 / 어떻게 풀었는지(또는 진행 중).
- 다듬지 않고 그날그날 적는다. 완성도는 나중에 월말 회고나 블로그 글을 쓸 때 챙긴다.
- 파일은 연도 폴더 아래 월 단위로 모아서 관리한다.

## 폴더 구조

```
dev-log/
├── README.md
└── 2026/
    └── 09.md   ← 이번 달 기록
```

매달 `YYYY/MM.md` 파일을 새로 만들고, 그 안에 날짜별로 항목을 추가합니다.

## 항목 템플릿

```markdown
## MM-DD (요일)

- 한 일:
- 막힌 것:
- 어떻게 풀었는지 / 진행 상황:
```
